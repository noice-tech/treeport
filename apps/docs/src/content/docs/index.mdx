## Features

- [Git worktrees](/concepts/projects-worktrees-terminals/): Create separate workspaces or open existing worktrees and folders.
- [Coding agents](/building-apps/coding-agents/): Pi is the only supported integration.
- [Persistent terminals](/features/persistent-terminals/): Keep processes running when you disconnect.
- [Terminal presets](/features/terminal-presets/): Save and reuse commands.
- [Packages](/features/packages/): Add terminal presets and web panels.
- [Browser](/features/browser-panel/) and [web panels](/features/web-panels/) (experimental): Open websites and project tools beside terminals.
- [Remote access](/features/remote-access/): Connect from another computer or phone through Tailscale.
- [Service supervision](/features/service-supervision/): Start automatically and restart after an unexpected exit.
- [Tree setup and cleanup](/features/worktree-setup-hooks/): Run commands when creating or removing a tree.
