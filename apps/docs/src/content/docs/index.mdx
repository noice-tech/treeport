Treeport is a workspace for coding agents, terminals, browser tabs, and custom apps. Run an agent, open the app it's building, and review its changes in the same tree.

## A workspace for each task

Open a project and create a tree for each task. Each tree has its own Git worktree and apps, keeping files and sessions separate while you work on several changes. You can also open existing worktrees or ordinary folders.

[Learn about projects, trees, and apps →](/concepts/projects-worktrees-terminals/)

## Agents and their tools

Run an agent and a development server in separate persistent terminals, then open the result in a browser. The Pi integration lets your agent manage terminals, interact with visible browser tabs, and work in separate trees.

[Set up a coding agent →](/building-apps/coding-agents/)

## Browsers and custom apps

- Open websites and development servers in [browser tabs →](/features/browser-app/) that you and your agent can use.
- Add a diff viewer, editor, dashboard, or another project tool with [web apps →](/features/web-apps/). Apps can use managed backend services.
- Install [packages →](/features/packages/) to add apps and reusable terminal commands to any project.

## Keep work running

Agents, development servers, and other terminal programs keep running when you close the client or disconnect. Reconnect to the same host from the macOS app or a browser, including from another computer or phone through Tailscale.

The host must stay running for these processes to continue.

[Terminals →](/features/persistent-terminals/) · [Remote access →](/features/remote-access/)
