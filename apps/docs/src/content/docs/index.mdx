## Start each task in a Tree

A Tree is Treeport's persistent workspace for a Git worktree. Use Trees for coding agents, shells, and development servers.

<CardGrid>
  <Card title="Use your Trees" icon="seti:git">
    Treeport finds Git worktrees and shows each one as a Tree.
  </Card>
  <Card title="Keep terminals active" icon="seti:shell">
    Terminal processes continue when you disconnect.
  </Card>
  <Card title="Connect from another device" icon="laptop">

## Use a standard application interface

Treeport gives terminal tools a familiar application interface. You can use tabs, mouse navigation, editors, agents, and pull-request workflows.

Treeport uses existing tools. It does not replace them.

Read the [Treeport design principles](/concepts/philosophy/).
