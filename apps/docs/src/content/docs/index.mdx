## A worktree is a piece of work

Treeport turns each Git worktree into a persistent workspace. Run coding agents, shells, development servers, test watchers, and normal TUIs side by side without adding another task database on top of Git.

<CardGrid>
  <Card title="Worktree-first" icon="seti:git">
    Treeport discovers the main checkout and every linked worktree reported by
    Git—even worktrees created by another tool.
  </Card>
  <Card title="Real, persistent terminals" icon="seti:shell">
    Applications run unchanged in an application-owned tmux server. Closing a
    client detaches it; the process keeps running.
  </Card>
  <Card title="Open from anywhere" icon="laptop">
    Use the desktop companion, browser, or responsive PWA to return to the same
    repositories, worktrees, and sessions.
  </Card>
  <Card title="Built for agents and humans" icon="puzzle">
    Start Pi, Claude Code, Codex, a shell, or any other terminal program. Use
    the CLI and standard terminal signals for automation.
  </Card>
</CardGrid>

## Git stays authoritative

Treeport does not hide worktree paths, branches, revisions, or dirty state. It continuously reconciles with Git and uses conservative safety checks before cleanup.

```text
Repository
├── main
│   ├── shell
│   └── dev server
├── investigate-terminal-resize
│   ├── Pi
│   └── test watcher
└── improve-mobile-layout
    └── Claude Code
```
