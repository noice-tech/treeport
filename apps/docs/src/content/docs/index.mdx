## Keep each task in its own Git worktree

Treeport gives each Git worktree a persistent workspace for terminals and tools. The interface calls this workspace a tree.

  <Card title="Use Git worktrees" icon="seti:git">

  <Card title="Keep terminals active" icon="seti:shell">

## Use a standard application interface

Treeport gives terminal tools a familiar application interface. You can use tabs, mouse navigation, editors, agents, and pull-request workflows.

Treeport uses existing tools. It does not replace them.

Read the [Treeport design principles](/concepts/philosophy/).
