---
title: Projects, trees, and terminals
description: Organize your work in projects, trees, and terminals.
---

```text
Project
└── Tree
    └── Terminal
```

- **Project:** A Git repository or ordinary folder opened in Treeport.
- **Tree:** A workspace for one Git worktree. An ordinary folder project has one tree.
- **Terminal:** A shell, Pi session, development server, or another terminal program in a tree.

Treeport finds existing Git worktrees. You can also create trees in Treeport to work on separate tasks.

Each tree can have multiple named terminals. For example, keep Pi, a development server, and tests in separate terminals.

Closing a project does not stop its terminals or delete files. Open it again to reconnect.
